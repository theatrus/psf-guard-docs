Plan the framing, mosaic and exposure plans for every rig. Shoot with N.I.N.A.: activation writes Target Scheduler projects. The PSF Guard Sync plugin sends plans and reviewed grades to the rig and uploads capture records and image files to PSF Guard. Grade every frame from its pixels and reject the clouded, blocked, soft and off-target ones. Stack and export: calibrated stacks, color previews, WBPP runs and AstroBin exports.

Like Lightroom Classic, for astrophotography data. PSF Guard catalogs files where they are. It keeps its image map, plans and grades in the Target Scheduler database layout, so it opens a live scheduler database the same way as one it built. Target Scheduler is optional.

Star count and HFR miss bad frames. In one test session a tree line crept into the field: star counts stayed within normal spread, and HFR held flat until 60% of the frame was blocked. A thin veil cut star brightness by 37% and still passed. PSF Guard checks each frame's local, photometric and temporal statistics, tuned on real sessions, and says what it found.

What PSF Guard does

🗃️

Catalog in place

Build a catalog from FITS or XISF folders, or open a Target Scheduler database. New frames come in on a schedule. Files never move.

🖼️

Fast grading

The same UI in the desktop app or a browser: stretched previews, linked comparison, batch selection, keyboard grading, and undo.

☁️

Quality screening

Spatial, photometric and SNR evidence, fresh plate solves and HFR against the target's best night flag clouds, obstructions, soft stars, rotator slips and lost pointing, with the reason on every card.

🔬

Stacks

Stack each channel with noise weighting and local normalization, calibrated by the library's own masters, then compose LRGB or narrowband color. New frames restack only what changed, and the library lists lights it cannot calibrate.

🧪

WBPP on the server

Run PixInsight's WeightedBatchPreprocessing from Stacks, headless, with each night's flats and darks matched. Its masters come back as stacks.

🧫

Calibration you can check

Every bias, dark and flat is graded. Flats are grouped by what they measure, dust and vignetting are drawn, and each light says which flats it takes and why. Projects the library serves poorly are flagged.

🎯

Planning across rigs

Frame a target or mosaic on survey images, set goals per filter, check tonight's visibility from each rig, and write the plan into every rig's Target Scheduler database.

🗺️

Sky coverage & Live

Every field from every rig on one sky, with your stacks in place and a timeline of every night. Rigs on the Director plugin, an early beta, show where they point.

🌌

Plate solving

Seiza solves frames on demand and overlays catalog objects, an RA/Dec grid and the target offset. Satellite trails are checked against predictions.

📤

Export

Export accepted lights with matched calibration, laid out for WBPP or by target, and write AstroBin's acquisition CSV.

🔁

Sync & remote rigs

Connect N.I.N.A. through the PSF Guard Sync plugin, the recommended setup with Target Scheduler. Sync capture records, plans and grades, and optionally upload image files.

🤝

Collaboration

An early beta: join AstroCollab projects such as Starfront, pull tonight's work into a rig, and report frames that pass review.

🤖

MCP for agents

Connect Claude Code or Codex from Settings. An agent reads grades, stacks, calibration and plans, and changes them as you would, with your permissions.

💾

Backups

Back up the settings and every catalog into one archive, now or on a schedule, while N.I.N.A. keeps writing. psf-guard backup does the same from cron or a timer.

See why a frame failed

Sequence scores a whole session at once and gives the cause of each low score. Annotated diagnostics mark the cells where a frame broke its own baseline.

Stack and process without leaving the grader

Stacks sits beside Images and Sequence. Each channel stacks from the frames you accepted, with calibration from the library and a signal-to-noise curve that says whether more frames still pay. Combine channels in color, or hand the project to WBPP on the server.

See the calibration each light gets

The Calibration page shows a rig's bias, darks and flats night by night, each graded against the frames like it. Flats are grouped by what they measure, so new dust or a moved camera starts a new group, and each light takes flats from its own side of the change. Keep a frame out, use it anyway, or split a group by hand.

A quick tour

Install

A desktop app, a Docker image, standalone binaries and a Fedora RPM.

🖥️ Desktop app

Installers for Windows, macOS (Apple Silicon) and Linux (.deb or AppImage).

Download the latest release →

🐳 Docker

For a NAS or home server. Keep /data on a volume; the catalog must be writable.

docker run -d -p 3000:3000 \
  -v psf-guard-data:/data \
  -v /path/to/catalog.sqlite:/data/database.sqlite \
  -v /path/to/images:/images:ro \
  ghcr.io/theatrus/psf-guard:latest

⌨️ Standalone CLI

Serve the UI, screen a night of frames, or script imports and exports.

psf-guard screen-fits ./LIGHT --annotate ./diag
psf-guard server catalog.sqlite ./images
