PSF Guard catalogs your FITS and XISF frames in place, grades them by target, night and filter, and flags clouds, obstructions, soft stars and bad pointing from the pixels. Stack what passes, export it for PixInsight, and plan the next nights across every rig in N.I.N.A.'s Target Scheduler.

Like Lightroom Classic, for astrophotography data. PSF Guard catalogs files where they are. It keeps its image map, plans and grades in the Target Scheduler database layout, so it opens a live scheduler database the same way as one it built. Target Scheduler is optional.

More from us: seiza.fyi — live plate solving in your browser, plus desktop apps for FITS browsing. Chatstronomy watches your N.I.N.A. rigs and posts captures, autofocus results and status to Discord or Matrix.

Star count and HFR miss bad frames. In one test session a tree line crept into the field: star counts stayed within normal spread, and HFR held flat until 60% of the frame was blocked. A thin veil cut star brightness by 37% and still passed. PSF Guard checks each frame's local, photometric and temporal statistics, tuned on real sessions, and names what it found.

What PSF Guard does

🗃️

Catalog in place

Build a catalog from FITS or XISF folders, or open a Target Scheduler database. New frames come in on a schedule. Files never move.

🖼️

Fast grading

The same UI in the desktop app or a browser: stretched previews, linked comparison, batch selection, keyboard grading, and undo.

☁️

Quality screening

Spatial, photometric and SNR evidence, fresh plate solves and HFR against the target's best night flag clouds, obstructions, soft stars, rotator slips and lost pointing, with the reason on every card.

🔬

Stacks

Stack each channel with noise weighting and local normalization, calibrated by the library's own masters, then compose LRGB or narrowband color. New frames restack only what changed.

🧪

WBPP on the server

Run PixInsight's WeightedBatchPreprocessing from Stacks, headless, with each night's flats and darks matched. Its masters come back as stacks.

🎯

Planning across rigs

Frame a target or mosaic on survey images, set goals per filter, check tonight's visibility from each rig, and write the plan into every rig's Target Scheduler database.

🗺️

Sky coverage & Live

Every field from every rig on one sky, with your stacks in place, a timeline of every night, and live rigs drawn where they point.

🌌

Plate solving

Seiza solves frames on demand and overlays catalog objects, an RA/Dec grid and the target offset. Satellite trails are checked against predictions.

📤

Export

Export accepted lights with matched calibration, laid out for WBPP or by target, and write AstroBin's acquisition CSV.

🔁

Sync & remote rigs

Move projects, captures, plans and grades between a telescope database and a grading copy, on one machine or between PSF Guard servers.

🤝

Collaboration

Join AstroCollab projects such as Starfront, pull tonight's work into a rig, and report frames that pass review.

🤖

MCP for agents

An MCP server and API tokens let an agent such as Claude read grades and evidence, apply grades, and start scans and WBPP runs.

See why a frame failed

Sequence scores a whole session at once and names the cause behind each low score. Annotated diagnostics mark the cells where a frame broke its own baseline.

Stack and process without leaving the grader

Stacks sits beside Images and Sequence. Each channel stacks from the frames you accepted, with calibration from the library and a signal-to-noise curve that says whether more frames still pay. Combine channels in color, or hand the project to WBPP on the server.

Plan the next nights across every rig

Every database is a rig and every project a plan. Frame a target or mosaic the way N.I.N.A.'s framing assistant does, on online surveys or offline sky maps; give each rig its panels and goals; see tonight's visibility from each site; then activate to write Target Scheduler projects, targets and exposure plans, with a preview of every row.

Everything you have imaged, on one sky

The Sky view maps every target from every database, equatorial or galactic, flat or as a globe. Zoom in to see each target's latest stack placed by its plate solve. A timeline replays every night per rig, and Live shows each rig where it points now.

Know where every frame landed

A quick tour

Install

A desktop app, a Docker image, standalone binaries and a Fedora RPM.

🖥️ Desktop app

Installers for Windows, macOS (Apple Silicon) and Linux (.deb or AppImage).

Download the latest release →

🐳 Docker

For a NAS or home server. Keep /data on a volume; the catalog must be writable.

docker run -d -p 3000:3000 \
  -v psf-guard-data:/data \
  -v /path/to/catalog.sqlite:/data/database.sqlite \
  -v /path/to/images:/images:ro \
  ghcr.io/theatrus/psf-guard:latest

⌨️ Standalone CLI

Serve the UI, screen a night of frames, or script imports and exports.

psf-guard screen-fits ./LIGHT --annotate ./diag
psf-guard server catalog.sqlite ./images
