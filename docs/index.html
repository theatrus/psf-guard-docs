Getting Started

Install PSF Guard and connect N.I.N.A. through the PSF Guard Sync plugin, import existing FITS or XISF folders, or open a Target Scheduler database. Review your frames, plan future captures and build calibrated stacks without using the command line.

1. Install

The desktop app runs on Windows, macOS and Linux. Docker, standalone CLI binaries and Fedora RPMs serve the same UI to a browser.

3. Connect N.I.N.A. with PSF Guard Sync

For N.I.N.A. with Target Scheduler, use the PSF Guard Sync plugin. Target Scheduler runs your imaging sessions. The Sync plugin sends capture records to PSF Guard and retrieves saved plans and reviewed grades. You can also upload saved lights and calibration frames.

  1. Install PSF Guard Sync from the PSF Guard plugin repository in N.I.N.A.
  2. In PSF Guard, choose the destination catalog under Settings → Databases. If you need a new catalog, create one from an empty image folder; the plugin can populate it.
  3. Edit the catalog and generate a pairing code. Enter the server URL and code in the N.I.N.A. plugin, then click Pair and Test connection.
  4. Choose which data to sync. If you also want to transfer image files, enable uploads and choose a receive folder in PSF Guard.

Follow Pair N.I.N.A. with a catalog for the full setup. The Sync plugin transfers data; Target Scheduler remains responsible for capture. You do not need the Director beta for this setup.

Or import existing images

Open Settings → Databases → New Database from Images, add your image folders, and choose Create & Import. PSF Guard groups frames into projects, targets and exposure plans from the headers alone. Turn on Automatic import to bring in new frames on a schedule; PSF Guard holds frames for unknown targets until you choose Review and approve their import. See Import Images.

Or open a Target Scheduler database

Back up the database before PSF Guard first writes to it. Grading writes to the file. Import and sync preview their changes first. Use Backups to copy catalogs safely while N.I.N.A. runs.
  1. Open Settings → Databases → Add Database.
  2. Pick the SQLite file and add the folders that hold its images. On Windows the file is usually %LOCALAPPDATA%\NINA\SchedulerPlugin\schedulerdb.sqlite.
  3. Choose a project in the Library; it opens in Images.

Image folders can be read only. The database file must be writable to save grades and plans.

4. Review a project

  1. In the Library, pick a project. Its row shows the database, state, accepted against desired, grading counts and capture dates.
  2. In Images, filter by status, filter or quality flag. Move with the arrow keys, select with Space, accept with A and reject with X.
  3. Open Sequence to see a whole session scored, with the cause behind each low score.
  4. Open Calibration to review the bias, dark and flat frames matched to your lights. If the Library shows a Poor or Check badge, click it to see the calibration findings.
  5. Open Stacks to stack the accepted frames per channel and combine them in color.
  6. Export the accepted lights for PixInsight, or run WBPP on the server.

5. Plan across rigs

PSF Guard creates rigs and plans from your registered databases and Target Scheduler projects. Open a plan's Planning workspace to frame it on the sky, set goals per filter, and write it into each rig's Target Scheduler database. See Planning.

Other ways to connect a rig

If PSF Guard can open the telescope's database directly, you can work on that file without syncing a second copy. For separate database files, use Data Transfer to copy captures, plans and grades. If another site runs its own PSF Guard server, connect through Remote PSF Guard. For N.I.N.A. rigs, the Sync plugin is the recommended way to automate these transfers.

Early beta: Director and collaboration

The upcoming N.I.N.A. Director plugin is a separate integration for plan execution and live rig status. Its early beta can retrieve an activated program, report status and check in saved captures. Direct acquisition is still upcoming, and pairing alone does not start a sequence or grant equipment control. Use Target Scheduler with PSF Guard Sync for imaging today.

Collaboration is also in early beta. It connects rigs to shared imaging projects on services such as Starfront, imports assigned work and submits accepted contributions.

Image formats

PSF Guard reads FITS (.fits, .fit, .fts) and monolithic XISF. FITS images in an extension, tile-compressed (fpack), signed 16-bit and 64-bit integer images all open. Raw one-shot-color frames with a BAYERPAT header show in color (C switches); grading measures their luminance.
