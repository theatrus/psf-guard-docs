Getting Started

Install PSF Guard, then build a catalog from FITS or XISF folders or open a N.I.N.A. Target Scheduler database. Image files stay where they are. No command line needed.

1. Install

The desktop app runs on Windows, macOS and Linux. Docker, standalone CLI binaries and Fedora RPMs serve the same UI to a browser.

Like Lightroom Classic, for astrophotography data. PSF Guard catalogs files in place. It keeps its image map, plans and grades in the Target Scheduler database layout, but Target Scheduler is optional.

3. Build a catalog

Open Settings → Databases → New Database from Images, add your image folders, and choose Create & Import. PSF Guard groups frames into projects, targets and exposure plans from the headers alone. Turn on Automatic import to bring in new frames on a schedule. See Import Images.

Or open a Target Scheduler database

Back up the database before PSF Guard first writes to it. Grading writes to the file. Import and sync preview their changes first.
  1. Open Settings → Databases → Add Database.
  2. Pick the SQLite file and add the folders that hold its images. On Windows the file is usually %LOCALAPPDATA%\NINA\SchedulerPlugin\schedulerdb.sqlite.
  3. Choose a project in the Library; it opens in Images.

Image folders can be read only. The database file must be writable to save grades and plans.

4. Review a project

  1. In the Library, pick a project. Its row shows the database, state, accepted against desired, grading counts and capture dates.
  2. In Images, filter by status, filter or quality flag. Move with the arrow keys, select with Space, accept with A and reject with X.
  3. Open Sequence to see a whole session scored, with the cause behind each low score.
  4. Open Stacks to stack the accepted frames per channel and combine them in color.
  5. Export the accepted lights for PixInsight, or run WBPP on the server.

Next: Library & Grader, Quality Screening, Stacks and Export.

5. Plan across rigs

Every database is a rig and every project a plan. Open a plan's Planning workspace to frame it on the sky, set goals per filter, and write it into each rig's Target Scheduler database. See Planning.

Two-machine setups

Skip sync when PSF Guard can open the telescope's database directly. Sync is for two separate database files: pull captures to the grading copy, then push plans and reviewed grades back. A rig at another site can run its own PSF Guard; sync with it over the network with Remote PSF Guard. See Rejects & Sync.

Image formats

PSF Guard reads FITS (.fits, .fit, .fts) and monolithic XISF. FITS images in an extension, tile-compressed (fpack), signed 16-bit and 64-bit integer images all open. Raw one-shot-color frames with a BAYERPAT header show in color (C switches); grading measures their luminance.
