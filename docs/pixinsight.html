PixInsight Scripts

The PixInsight scripts are a theatr.us tool rather than part of PSF Guard, and their guide lives there: Foraxx palette for PixInsight and Photoshop. The palette itself is The Coldest Nights' dynamic narrowband combination.

In short

  1. In PixInsight, open Resources → Updates → Manage Repositories and add https://pixinsight.theatr.us/, including the trailing slash.
  2. Run Check for Updates, accept, and restart PixInsight.
  3. The scripts appear under Script → theatr.us.
The earlier address https://pixinsight.psf-guard.com/ still works and serves the same files. Everything else, from the palette math to every option, is in the guide on theatr.us.

Why it pairs with PSF Guard

PSF Guard decides which frames to keep and can build the stacked narrowband masters; the Foraxx script is one way to turn those masters into a palette image. Seiza, which powers PSF Guard's stacking, can also render the Foraxx palette directly.
