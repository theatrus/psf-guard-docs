PixInsight Scripts

The PixInsight scripts, the Foraxx palette utility among them, are a theatr.us tool rather than part of PSF Guard. This page covers installing them and how PSF Guard works with PixInsight.

Install the scripts

  1. In PixInsight, open Resources → Updates → Manage Repositories and add https://pixinsight.theatr.us/, trailing slash included.
  2. Run Check for Updates, accept, and restart PixInsight.
  3. The scripts appear under Script → theatr.us.
The old address https://pixinsight.psf-guard.com/ still serves the same files. The palette math and every option are in the guide: Foraxx palette for PixInsight and Photoshop. The palette is The Coldest Nights' dynamic narrowband combination.

Use them with PSF Guard

PSF Guard decides which frames to keep and stacks the narrowband channels. The Foraxx script is one way to turn those masters into a palette image. Seiza, which runs PSF Guard's stacking, also renders Foraxx SHO and Foraxx HOO directly in Stacks.

Run WBPP from PSF Guard

PSF Guard can hand a project to PixInsight's WeightedBatchPreprocessing in two ways:

  • Stack in WBPP runs WBPP on the server and brings the masters back as stacks. See WBPP Runs.
  • A WBPP export writes the frames, or just a script that names them, with run-wbpp.js and launchers to run on any machine. See Export & AstroBin.

Open FITS and XISF masters in Photoshop

For a Photoshop finish, the FITS and XISF plugins open and save both formats on Windows and macOS. Import as 32-bit float or rescaled 16-bit, and save at the document depth. Read install, settings and file preservation before editing your masters.
