N.I.N.A. Sync Plugin

PSF Guard Sync is a N.I.N.A. plugin that keeps a live Target Scheduler catalog in step with a PSF Guard server: upload each saved light, push scheduler captures as they land, and exchange plans and reviewed grades without the two-database CLI sync dance.

Beta channel, working end to end. PSF Guard Sync 0.2.0.0 speaks the versioned /api/sync/v1 protocol implemented by PSF Guard 0.6.1 and newer. Both direct image upload and Target Scheduler catalog synchronization are available now.

Install it in N.I.N.A.

PSF Guard hosts its own N.I.N.A. plugin repository. Add it as a plugin source and PSF Guard Sync installs and updates like any other plugin:

  1. In N.I.N.A., open Options → Plugins.
  2. Add this repository URL: 
    https://nina-plugins.psf-guard.com/
  3. Turn on “Include beta versions” — PSF Guard Sync ships on the beta channel.
  4. Find PSF Guard Sync in the Available list, install it, and restart N.I.N.A.
Requires Windows x64, N.I.N.A. 3.2.0.9001 or newer, and PSF Guard 0.6.1+. Target Scheduler schema 22+ is required for catalog sync, but not for direct FITS upload. The registry lives at nina-plugins.psf-guard.com.

Prepare the PSF Guard server

  1. Open Settings → Databases and edit the destination catalog.
  2. Choose Generate beside Remote API key, then copy the key while it is visible.
  3. Enable Remote scheduler sync. If the plugin will upload image files directly, also enable Remote image uploads and choose one of that catalog's configured image directories.
  4. Save the catalog and record its ID from the database list or its ?db= URL value.

The server keeps only a salted digest of an incoming key, so it cannot show the key again. Generating a replacement invalidates the old value. Scheduler sync and image upload are separate grants even though they use the same catalog-scoped key.

A browser-managed server needs database management enabled and an editor login to change this catalog configuration. See Server Accounts for the network-server access model.

How it works

The plugin subscribes to N.I.N.A.'s image-saved event and can use either of two capture paths. Direct image mode queues the saved light itself; PSF Guard verifies its digest and imports it from the FITS headers. Target Scheduler mode waits briefly for the matching acquiredimage row, then queues a schema-preserving bundle containing the capture and its project, target, and plan dependencies. Network work never blocks the image-save pipeline — an unavailable server simply leaves work in the durable retry queue.

  • Direct image upload — send saved FITS lights without installing Target Scheduler.
  • Automatic catalog push — queue each light after Target Scheduler records it, including the scheduler metadata PSF Guard needs to preserve the plan.
  • Durable, idempotent queue — bundles live under %LOCALAPPDATA%\NINA\PsfGuardSync, survive restarts, and re-send safely.
  • Two-way, on demand — manual full merge, planning push, and reviewed-grade push, plus planning and grade pull back into Target Scheduler.
  • Stable identity — matches images by GUID, remaps parent IDs for projects, targets, templates, and plans, and preserves the telescope-side acquired/accepted counters. Grade pulls touch only gradingStatus and rejectreason.
  • Optional thumbnails — transfer Target Scheduler thumbnails alongside the capture.

Configure it

Open Plugins → Installed → PSF Guard Sync and set:

  1. The PSF Guard server URL.
  2. The destination PSF Guard catalog ID.
  3. The Remote API key copied from PSF Guard. The plugin stores it in Windows Credential Manager.
  4. For catalog sync, the Target Scheduler database path (default %LOCALAPPDATA%\NINA\SchedulerPlugin\schedulerdb.sqlite).
  5. Choose direct FITS upload, Target Scheduler catalog push, or both, plus the preview-apply policy for catalog changes.

Use Test connection before enabling automatic work. It checks the URL, API key, selected catalog, protocol version, and server grants.

Sequencer instructions

The plugin also contributes instructions under PSF Guard Sync in the advanced sequencer:

  • Check PSF Guard connection — verifies the server, API token, and selected catalog. Place it near the start of a session so a remote outage follows the instruction's configured error behavior.
  • Pull PSF Guard planning — applies remote projects, targets, templates, and plans to Target Scheduler. Run it before a Target Scheduler container starts; a running container may keep its in-memory plan.
  • Pull PSF Guard grades — applies reviewed grades and rejection reasons by unambiguous acquired-image GUID.
  • Reconcile PSF Guard catalog — pushes a fresh full scheduler snapshot, waits for PSF Guard's preview, and optionally applies it. This is useful at the end of a session.
  • Reconcile current target with PSF Guard — does the same for only the enclosing target. Place it near the end of that target's container; ambiguous Target Scheduler target names are refused instead of guessed.

Reconciliation instructions wait for final Target Scheduler transactions and then wait for the server preview, so they are real sequence barriers. Automatic per-capture pushes keep retrying independently in the background.

Troubleshooting

ResultCheck
401 or “Bearer token required”The plugin has no Remote API key. Copy or replace it, then run Test connection.
403 invalid key or wrong catalogThe key is catalog-scoped. Confirm the destination catalog ID and generate a new key if the old one was replaced.
403 scheduler sync disabledEnable Remote scheduler sync on that PSF Guard catalog. Image upload permission alone does not grant catalog changes.
404 under /api/sync/v1Upgrade the PSF Guard server to 0.6.1 or newer. A 404 for an older preview can also mean its 30-minute lifetime ended or it was already applied.
Queued work does not drainRun Test connection, confirm N.I.N.A. can reach the server URL, then leave the plugin running; its durable queues resume automatically.
Working from one machine, or syncing two SQLite files directly? The CLI psf-guard sync commands do the same job between database files, without the plugin.
